# Батл пасс по циклам (идея begimotgrass, 2026-09-15)

## Что хотим
500 уровней = 50 циклов по 10 уровней, у каждой позиции цикла свой смысл:

| поз. | награда |
|---|---|
| 1 | деньги |
| 2 | мелочь (выбор) |
| 3 | опыт / еда — через цикл (после 200 еды нет → опыт) |
| 4 | мелочь (выбор) |
| 5 | ресурс (выбор), 32+ и растёт со временем |
| 6 | «помогает на этапе» (душные крафты) |
| 7 | деньги |
| 8 | помогает на этапе / опыт — через цикл |
| 9 | мелочь (выбор) |
| 10 | Void Coin (случайное количество) |

- Особые уровни: 50/150/250/350/450 — дорогое, 100/200/300/400/500 — очень дорогое.
- Зоны: 1–100 начальные технологии, 101–200 продвинутые, 201–300 мидгейм, 301–400 пред-эндгейм, 401–500 эндгейм.
- Вход в зону по условию: пока не открыта эпоха — XP дальше границы зоны не копится, награды выше не забираются.
- Выбор награды (игрок выбирает 1 из вариантов), случайное количество (от–до).
- Уровень 1: free — пистолет, premium — автомат на выбор.

## Решения (интерпретация, проговорить с бегемотом)
- Premium идёт по той же сетке, но щедрее: ×2 количества, варианты на тир лучше.
- Условия зон = эпохи общей линии: 101 → Эпоха стали, 201 → Эпоха энергии, 301 → Эпоха автоматизации, 401 → Индустриальная эпоха.
- Уже набранный уровень не отнимаем: игрок выше границы просто не заберёт награды за ней, пока не откроет эпоху.
